Overview

What is Meo?

Meo Meo AI is a personal AI platform being built for useful, controlled work across PC and mobile devices. It brings together an assistant, durable research and knowledge, safe agent workflows, and modular applications.

The project is provider-neutral. AI models can support reasoning and execution, but they do not own permissions or canonical personal state.

Read the English product, founder and progress overview for maturity labels, recorded milestones, Claude’s review history and intended use.

Trust model

Local-first philosophy

Meo PC remains the canonical authority. Public cloud infrastructure may host this website, public status, documentation, and approved release metadata. It does not host private memory, raw private research, secrets, credentials, canonical transactional data, private source, or unrestricted device-control capability.

Future device interaction must continue through explicit owner approval and bounded capabilities. Cloud infrastructure does not grant itself authority.

Maturity

Current development status

Meo Meo AI is a personal, self-funded project under active development by Ngoc, an independent founder in Vietnam. There is no registered company yet, no investors and no institutional funding. Internal builds and bounded experiments are not a production-ready platform.

See the public status page for project-area states. There are no public binary releases yet.

Safety

Release verification

Only downloads listed on the releases page are public releases. Future artifacts will include a SHA-256 checksum in /api/version.json . Verify that checksum locally before use.

Signature-related fields exist for future compatibility, but signed updates are currently off. No production signing keys are generated or published.
