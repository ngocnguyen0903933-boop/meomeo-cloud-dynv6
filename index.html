Why Meo exists

Personal AI, on the user’s terms.

Ngoc is an independent founder in Vietnam building a practical, affordable assistant for personal devices and real-world work. The goal is to make research and everyday workflows more continuous without asking users to hand control of their data or devices to a cloud model.

Meo Meo AI is a personal, self-funded project under active development. It has no registered company yet, no investors and no institutional funding.

Built foundations are not a finished platform. Android builds, shared-core checks, a PC runtime proof of concept and a bounded multi-model research experiment exist internally. Broader device interaction and dependable everyday operation remain development goals. Read the English product overview, milestones and limits →

AI + Claude

Independent critique. Local authority.

Claude served as an early independent AI architecture reviewer. The project’s Shared Core v0.3 record explicitly incorporates Claude v0.2 feedback, helping clarify system boundaries, data integrity and governance. This is a record of AI-assisted review—not an Anthropic partnership or evidence of a production Claude API integration.

Why Claude matters next

Planned uses include code and architecture review, independent security and failure-mode analysis, and research critique with evidence comparison. Startup program support would help evaluate, integrate and test these workflows within a self-funded project’s budget.

Teacher → Core → Tool

Models advise; Meo’s local Core validates; approved tools execute within human-authorized boundaries. Future Claude provider integration depends on authorization, validation, costs and API terms. Providers stay replaceable, and the Owner retains authority.
